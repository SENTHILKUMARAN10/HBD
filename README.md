# BEZATI • 26.08.26 — V6

Premium dark-mode birthday surprise website for Bezati.

## V6 updates
- Added the supplied high-resolution Spider-Man PNG as the main animated hero character.
- Added the supplied spider PNG as a subtle 3D-style floating Spider-Verse decoration across the site.
- Added a second low-opacity Spider-Man depth layer for the rest of the page.
- Added animated web portal/decorations across the website.
- Added the supplied `black_suit_theme.mp3` as the looping birthday soundtrack.
- The site attempts to autoplay the soundtrack. Browser autoplay policies may require the first tap/click; the intro YES button also starts it.
- Added a floating mute/play control.
- Added lightweight synthesized button/game/gift/menu sound effects.
- Kept the existing intro gate, memories, letter, blessing, diamond, activities, locked gift, guitar reveal, and final message.
- All supplied visual/audio assets are local to the project; no remote asset dependency is required for them.
